# data/

Nothing in this folder is committed except this file. Code expects the layout below.

| Folder | What it is | How to get it |
|---|---|---|
| `avocado/` | Public Mendeley "Hass" avocado set (478 fruit, 14,710 daily photos, 3 storage temperatures; [10.17632/3xd9n945v8.1](https://doi.org/10.17632/3xd9n945v8.1), CC BY 4.0) | `python scripts/data/download_avocado.py` (resumable) |
| `a2sl/` | Lab avocados: side photos + microwave-scanner reconstructions at 6 rotation angles (0°–300°), 15 fruit | Lab data, not public. Copy from the project storage on the cluster, then `python scripts/data/ingest_a2sl.py`. Format: [`docs/data/data_a2sl.md`](../docs/data/data_a2sl.md) |
| `mango/` | Lab mangoes (Spring 2026, 48 fruit, one batch): cut-day firmness/hue/sweetness, cut-day photos, microwave scans every other day | Lab data, not public. Copy from the cluster, then `python scripts/data/ingest_mango.py` and `python scripts/data/ingest_mango_views.py` |
| `manifests/` | One CSV row per fruit / visit / scan, written by the ingest scripts | Generated by the ingest scripts above |
| `features/` | Frozen image-encoder features | `python scripts/data/extract_features.py` |

On the UMIACS cluster the full folder lives at `/fs/class-projects/fall2026/cmsc498z/nwajge/ripen/data/`; collaborators
with access can copy or symlink it. Tests that need the lab data skip when it is missing.

Other candidate datasets: [`docs/background/dataset_survey.md`](../docs/background/dataset_survey.md).
